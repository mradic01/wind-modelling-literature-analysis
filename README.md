# Wind Modelling Literature Analysis

This branch contains the scripts, classification dictionaries, and selected
outputs used for the systematic literature analysis presented in Chapter 5
of the qualification exam thesis _Artificial Intelligence and Machine Learning
for Wind Modelling and Prediction: Data Sources, Methods, and Research Gaps_.

The analysis is based on bibliographic records retrieved from the Web of
Science Core Collection.

## Analysis components

The literature analysis consists of four main components:

- classification of wind modelling approaches;
- classification of meteorological measurement and data sources;
- screening for alternative measurement sources;
- classification of performance and validation metrics.

### Modelling categories

The `modelling_categories` directory contains the script and classification
dictionary used to identify the main wind modelling approaches represented
in the literature.

### Measurement sources

The `measurement_sources` directory contains the script and dictionary used
to identify meteorological measurement and data-source categories reported
in the analysed publications.

### Alternative sources

The `alternative_sources` directory contains the additional screening
procedure used to identify less common and alternative meteorological
measurement sources.

### Validation metrics

The `validation_metrics` directory contains the script and classification
dictionary used to identify commonly reported model-performance and
validation metrics.

## Classification procedure

The analyses use rule-based keyword matching applied to bibliographic
information from the Web of Science records. Classification dictionaries
are included alongside the corresponding scripts to make the classification
criteria transparent.

## Outputs

Selected processed results generated by the analyses are provided in the
`output` directory. The outputs are organised according to the four analysis
components described above.

The original Web of Science bibliographic export is not included in this
repository.

## Requirements

The scripts require Python 3 and standard data-analysis packages, including:

```bash
pip install pandas openpyxl matplotlib
```
